### An ultra-high order Intrinsic Connectivity Network (ICN) template derived from more than 100,000 resting-state fMRI scans.

It is created from a model order of 500 components, yielding 131 non-artifactual networks organized based on the NeuroMark 2.2 template can be downloaded by clicking following link, [Neuromark_fMRI_2.2_modelorder-500.nii](https://github.com/trendscenter/gift/raw/master/GroupICAT/icatb/icatb_templates/NeuroMark_fMRI_1.0_modelorder-500/NeuroMark_fMRI_1.0_modelorder-500.nii), including the label file [Neuromark_fMRI_2.2_modelorder-500.txt](https://github.com/trendscenter/gift/raw/master/GroupICAT/icatb/icatb_templates/NeuroMark_fMRI_1.0_modelorder-500/NeuroMark_fMRI_1.0_modelorder-500.txt).

*** Note that the original label file is in .xlsx  format is [here](https://github.com/trendscenter/gift/raw/master/GroupICAT/icatb/icatb_templates/NeuroMark_fMRI_1.0_modelorder-500/NeuroMark_fMRI_1.0_modelorder-500.xlsx) and has more detailed information (such as individual ICN labels), but the .txt version is consistent with the other templates.
