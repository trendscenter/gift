### A multi-scale order Independent Component Network (ICN) Neuromark template.
It is created from 25, 50, 75, 100, 125, 150, 175, 200 components, yielding 105 non-artifactual and overlapping networks and can be downloaded by clicking following link, [Neuromark_fMRI_2.1_modelorder-multi.nii](https://github.com/trendscenter/gift/raw/master/GroupICAT/icatb/icatb_templates/Neuromark_fMRI_2.1_modelorder-multi.nii), including the label file [Neuromark_fMRI_2.1_modelorder-multi.txt](https://github.com/trendscenter/gift/raw/master/GroupICAT/icatb/icatb_templates/Neuromark_fMRI_2.1_modelorder-multi.txt).
