### An optimized high order fMRI Neuromark Templates derived from very large data (N~100K) was released in March, 2023.

A high order Intrinsic Connectivity Network (ICN) template, created from 175 components, yielding 58 non-artifactual networks. The network template is downloaded by clicking following link, [Neuromark_fMRI_2.0_modelorder-175.nii](https://github.com/trendscenter/gift/raw/master/GroupICAT/icatb/icatb_templates/Neuromark_fMRI_2.0_modelorder-175.nii), including the label file [Neuromark_fMRI_2.0_modelorder-175.txt](https://github.com/trendscenter/gift/raw/master/GroupICAT/icatb/icatb_templates/Neuromark_fMRI_2.0_modelorder-175.txt).

#### Reference:
A. Iraji, Z. Fu, A. Faghiri, M. Duda, J. Chen, S. Rachakonda, T. DeRamus, P. Kochunov et. al. “Identifying canonical and replicable multi-scale intrinsic connectivity networks in 100k+ resting-state fMRI datasets”, [Human brain mapping, 2023.](https://onlinelibrary.wiley.com/doi/full/10.1002/hbm.26472)
